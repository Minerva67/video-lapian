## 三、视觉设计语言分析

- **核心手法**：**"动效即演示"**。这支片的每一个转场、入场、数字滚动，本身就是用被宣传的功能做出来的；再配合固定的"推近控件 → 拉远看成品"镜头循环。观众看到的每一处动效，都是一次"Figma Motion 能做到这个"的证明。
- **色彩系统**：

| 色彩层 | 用途 | 色值/风格（抽帧取样，360p 有压缩偏差） |
|--------|------|------|
| 品牌黑 | 片名、Dev Mode、收尾 | #000000 |
| 橙红 | 片名 "Figma Motion"、slogan | #F0673C / #ED673C |
| 墨绿 + 青柠 | 开场网页、Motion tokens、"Cheddar" 品牌 | #19301E、#126B03、#E8FFC2 |
| 电光紫 + 淡紫 | 关键帧与缓动、"Goal Reached" | #4900C8、#CBB7FC、#EBE2FC |
| 中性灰 + 青柠/橙标记 | Animation styles 地图 | #CBD1D3 |
| 暖橙 → 深灰 | AI 生成一幕 | #F38F30 → #252525 |
| 石板蓝 → 画布灰 | 3D transform、协作 | #7589A2 → #565656 |
| 界面蓝 | 选框、播放头、关键帧、AI 按钮 | Figma 选择蓝（目测） |

- **色调切换节奏**：
```
浅灰 → 青柠/墨绿（成品网页）→ 黑（片名）
→ 电光紫 →【反转】淡紫（Unlocked 完成）→ 紫
→ 中性灰（地图）→ 暖橙 → 深灰（AI）
→ 石板蓝 → 画布灰（3D + 协作）
→ 浅青柠（tokens）→ 黑（Dev Mode）→ 黑（收尾 + logo）
```
  每个功能一个纯色世界，切功能 = 切底色，观众不需要字幕也知道换话题了。黑色只用在三处：片名、开发交付、收尾。

- **动态图形风格**：
  - 光标是唯一的人：箭头、抓手两种形态，移动带缓动，像真人在操作。
  - 运动路径点：用点的疏密把缓动曲线可视化。
  - 底色反转表示"完成"（0:19.5 Unlocked）。
  - 弹入（scale + 轻微回弹）是所有图标、卡片的默认入场。
  - 收尾时彩色几何形带着选择手柄组装成 logo，把品牌标志当成画布上的图层。

## 十、对产品功能发布视频的可参考模板

**提炼的脚本结构模板**：
```
Phase 1  成品先行（0–7s）
         从成品的一个局部（最好虚焦）起，连续拉远，最后露出产品界面。
         目的：先定质量基线，再揭示"这是用我们的产品做的"。
Phase 2  片名卡（3s）
         纯色底 + 产品名大字静止，周边素材持续微动。
Phase 3  基础能力深讲（10–12s）
         放大到一个组件 → 光标操作 → 把抽象参数可视化 → 回放 → 底色反转表示完成 → 拉远到成品。
Phase 4  功能轮播 ×N（每个 5–10s）
         每个功能一个专属纯色底；结构固定：推近控件 → 操作 → 拉远看成品。
         顺序按真实工作流排：做 → 做快 → 做好 → 一起做 → 统一做 → 交付。
Phase 5  交付收口（5–6s）
         给最终使用者（如工程师）一个"可复制/可落地"的动作特写。
Phase 6  回顾 + slogan + logo（5s）
         各幕成品缩小成拼贴 → slogan（与片名同色）→ 品牌元素组装成 logo → 约 1s 定版。
```

**关键制作要素清单**：

| 要素 | 本片的做法 | 可参考方向 |
|------|----------|-----------|
| 音乐 | 持续电子节拍音乐床（推断），"完成"时刻前留空拍 | 剪辑对拍；关键揭晓前抽掉半拍 |
| 节奏 | 约 1.2–1.4s 一个画面变化，换景多用推拉而非硬切 | 功能之间硬切，功能内部用连续推拉 |
| 文案 | 零营销句，全部用真实 UI 标签、参数、示例内容 | 能用真界面文字说明的，不加字幕 |
| 人物 | 无真人，光标当主角，协作者只以头像 + 光标出现 | 工具类产品用光标代入，比真人更贴近使用场景 |
| 转场 | 虚焦拉实、组件→成品拉远、底色反转、用功能本身做入场 | 让转场本身就是被宣传的能力 |
| 色彩 | 每个功能一个纯色世界；黑色只给片名/交付/收尾；橙红首尾呼应 | 用底色为功能分段，省掉章节字幕 |
| 示例内容 | 五个不同行业的示例项目，完成度都很高 | 示例要好看到"值得模仿"，同时覆盖目标用户的行业 |
| 收束 | 成品拼贴回顾 → slogan → 几何形组装 logo，定版约 1s | 回顾全片成品，品牌标志用产品自身的视觉语言拼出 |
| 时长 | 68s 讲 8 个功能 | 每个功能 5–10s；最基础的那个给最长时间 |

**最大启发**：**让成品先出场，再拉远揭示"这是用我们的工具做的"，并且在每一个功能上重复这个动作。** 观众不是在听功能介绍，而是在一次次确认"刚才那个好看的东西就是这么做出来的"。工具类产品的说服力来自成品质量，而不是功能数量。
